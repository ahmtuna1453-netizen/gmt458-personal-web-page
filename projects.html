IMPLEMENTATION NOTES

Two common web-map issues

A

Marker visibility threshold

The sample markers are only displayed at zoom level 11 or closer. This reduces clutter when the map is zoomed out. Try zooming in and out to test it.

B

Repeated world

Leaflet's tile layer uses noWrap: true and geographic bounds. OpenLayers uses wrapX: false for the tile source and multiWorld: false for the view.
